# #198 (ops-1): PEP 594 removed the stdlib `audioop` module in Python 3.13, which
# is what the current DEFAULT Raspberry Pi OS image ("trixie") ships. shazamio's
# transitive dep `pydub` imports `audioop` at import time, so on 3.13 `pip install`
# SUCCEEDS but `import shazamio` fails at runtime — surfacing only as a per-chunk
# recognition miss on the appliance. audioop-lts reinstalls the `audioop` module
# so the default image works; the marker keeps it off 3.11 (Bookworm/Legacy),
# which still has audioop in the stdlib. main.py probes the import at startup and
# fails loud if this is somehow missing.
audioop-lts>=0.2; python_version >= "3.13"
